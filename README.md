# 📚 교육비 사용 현황 대시보드

사내 교육비 예산(연간 50만원)의 사용 현황을 조회하고, 잔액 변동 시 Flow 메신저로 알림을 받을 수 있는 웹 대시보드입니다.

## 접속

https://rosarosakim.github.io/edu-book-dashboard/edu-book-dashboard.html

## 주요 기능

### 🔐 Flow 인증
- 사번(Flow ID) 입력 → Flow 메신저로 6자리 인증번호 발송
- 3분 타이머 기반 인증, 재전송 지원

### 💰 예산 요약
- 확정 사용 금액 / 진행중(잠정) 금액 / 남은 잔액을 한눈에 확인
- 시각적 프로그레스 바로 사용 비율 표시

### 📋 신청 내역
- 기간 · 과정명 · 금액 · 상태(완료/결재중/반려 등)를 테이블로 조회
- 모바일에서는 카드 뷰로 자동 전환

### 🔔 Flow 알람
- 교육비 잔액 변동 시 Flow 메신저 알림 수신 ON/OFF
- 토글 한 번으로 설정 변경
