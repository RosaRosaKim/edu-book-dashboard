# 투표 기능 설계

## 1. 기능 개요

엠로생활 탭에서 "투표"를 선택하면 팀원들에게 투표를 받아 결과를 취합하는 기능.

### 기본 플로우
```
[발의자] 투표 생성
  → 제목, 항목 입력
  → 옵션 설정 (단일/복수, 익명, 항목추가 허용)
  → 마감시간 설정 (기본 60분)
  → 멤버 선택 → Flow 알람 발송
  → 발의자 본인도 투표 참여

[투표자] Flow 메시지 내 "바로가기" 클릭
  → 투표 화면 자동 진입
  → 항목 선택 (단일: 라디오 / 복수: 체크박스)
  → confirm() 확인 후 투표 확정 (재투표 불가)
  → 실시간 결과 확인 (익명이면 마감 후 공개)
  → 항목 추가 허용 시 직접 입력 + 자동 투표

[마감 5분 전] 미투표자에게 리마인드 Flow 발송
[전원 투표 완료] 즉시 마감
[마감] 전체 참여자에게 결과 Flow 발송
```

---

## 2. 구현 상세

### 2-1. 투표 생성 화면

- **제목**: 필수 입력
- **항목**: 최소 2개, 동적 추가/삭제
- **옵션 토글**:
  - 복수 선택 허용 (기본 OFF = 단일)
  - 익명 투표 (기본 OFF)
  - 항목 추가 허용 (기본 OFF)
- **마감시간**: 슬라이더 10~120분 (기본 30분)
- **멤버 선택**: `getBizFlowUserList` API로 dept 포함 유저 로드, 부서원 기본 표시
- **템플릿**: 저장/불러오기 (이쏜미 템플릿과 동일 패턴)

### 2-2. 투표 화면 (투표자)

- 제목 + 마감시간 표시
- 항목 목록 (단일: 라디오 / 복수: 체크박스)
- 투표 버튼 → `showConfirm()` 커스텀 확인 → 확정
- 항목 추가 허용 시 하단에 직접 입력 필드 + 추가 버튼 (추가 즉시 자동 투표)
- **실시간 결과**: 투표 후 또는 비익명 투표 시 바 차트로 표시
- **익명 투표**: 마감 전에는 "투표 완료" 표시만, 마감 후 결과 공개
- 투표 완료 시 "투표 완료" 상태 표시 (변경 불가)

### 2-3. 실시간 결과 표시

- 각 항목별 투표 수 + 비율 바
- 비익명: 항목별 투표자 이름 표시
- 익명: 마감 후에만 투표 수 + 비율 표시 (이름 없음)
- 총 투표 인원 / 전체 인원 표시

### 2-4. 마감 처리

- **시간 마감**: `pollVoteClose` 5분 트리거 (이쏜미 트리거 공유 가능)
- **전원 투표 시 즉시 마감**
- **마감 5분 전 리마인드**: 미투표자에게 Flow 발송 (세션당 1회)
- **마감 시 결과 Flow**: 전체 참여자에게 발송

### 2-5. 데이터 저장소 — 구글시트

**`투표` 시트 (세션 마스터)** — 1세션 1행:
| 열 | 인덱스 | 내용 |
|----|--------|------|
| A | 0 | 세션ID (UUID) |
| B | 1 | 생성자 knoxId |
| C | 2 | 생성자 이름 |
| D | 3 | 제목 |
| E | 4 | 항목 JSON `["항목1","항목2",...]` |
| F | 5 | 마감시간 (절대시각) |
| G | 6 | 상태 (open/closed) |
| H | 7 | 생성시각 |
| I | 8 | 총 인원수 |
| J | 9 | 옵션 JSON `{multi,anon,addable}` |

**`투표응답` 시트 (투표자별 응답)** — 1투표자 1행:
| 열 | 인덱스 | 내용 |
|----|--------|------|
| A | 0 | 세션ID (FK) |
| B | 1 | 투표자 knoxId |
| C | 2 | 투표자 이름 |
| D | 3 | 선택 항목 JSON `["항목1"]` or `["항목1","항목2"]` |
| E | 4 | 투표 시각 |

**`투표템플릿` 시트** — 1사용자+1제목 1행:
| 열 | 인덱스 | 내용 |
|----|--------|------|
| A | 0 | knoxId |
| B | 1 | 제목 |
| C | 2 | 항목 JSON |
| D | 3 | 옵션 JSON |
| E | 4 | 수정시각 |

### 2-6. Flow 딥링크

```
https://rosarosakim.github.io/edu-book-dashboard/edu-book-dashboard.html?tab=life&vote={sessionId}
```

### 2-7. 결과 메시지 (전원 발송)

```
📊 점심 뭐 먹을까? (5명 참여)

1. 한식 — 3표 (60%)
2. 중식 — 1표 (20%)
3. 양식 — 1표 (20%)
```

비익명 시 투표자 이름 포함:
```
1. 한식 — 3표 (60%)
   김철수, 이영희, 정수진
```

### 2-8. 항목 추가

- 투표자가 직접 항목을 추가할 수 있음 (옵션 ON 시)
- 추가 시 해당 항목에 자동 투표 (단일 선택이면 그 항목만, 복수면 기존 선택에 추가)
- 추가된 항목은 다른 투표자에게도 실시간 반영
- 마스터 시트의 항목 JSON에 추가

### 2-9. 템플릿

- 이쏜미 템플릿과 동일 패턴
- 전체 공유, 즐겨찾기, 삭제는 본인만
- "다음" 클릭 시 자동 저장

## 3. GAS 액션

| 액션 | 핸들러 | 설명 |
|------|--------|------|
| `createVote` | `handleCreateVote` | 세션 생성 + Flow 발송 |
| `getVote` | `handleGetVote` | 세션 정보 + 내 투표 + 현황 |
| `submitVote` | `handleSubmitVote` | 투표 확정 (재투표 불가) |
| `addVoteItem` | `handleAddVoteItem` | 항목 추가 + 자동 투표 |
| `getVoteTemplates` | `handleGetVoteTemplates` | 템플릿 목록 |
| `saveVoteTemplate` | `handleSaveVoteTemplate` | 템플릿 저장 |
| `deleteVoteTemplate` | `handleDeleteVoteTemplate` | 템플릿 삭제 |
| `closeVote` | `handleCloseVote` | 수동 마감 (생성자만) |
| `pollVoteClose` | (5분 트리거) | 자동 마감 + 리마인드 |

## 4. Flow 메시지

| 메시지 | 함수 | 제목 | 본문 |
|--------|------|------|------|
| 초대 | `voteInvite` | `📊 {제목}` | `{시간} 마감` + 링크 |
| 리마인드 | `voteReminder` | `⏰ 투표 마감 5분 전!` | `아직 투표 안 했어! {시간}에 마감이야.` |
| 결과 | `voteResult` | `📊 {제목} 결과 ({N}명 참여)` | 항목별 득표수 + 비율 |

## 5. UX 상세

- **딥링크 진입 시**: 투표 섹션만 표시 (식단 알람, 이쏜미 숨김), 뒤로가기 시 전체 복원
- **모든 통신 버튼에 스피너**: 다음, 투표 시작, 투표하기, 항목 추가, 투표 마감 등
- **멤버 선택**: 로딩 완료 후 본인 부서원 기본 표시, 검색으로 전체 멤버 탐색
- **수동 마감**: 생성자만 가능, `showConfirm` 확인 후 즉시 마감 + 결과 발송
- **confirm/prompt 미사용**: 모든 확인은 `window.showConfirm()` 커스텀 UI 사용
